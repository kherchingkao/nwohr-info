無戶籍國民不友善法規列表

台灣社會制度以每個國民均有戶籍為前提建立，並以國持民身分證作為享有各項權利的必要條件。在台灣，無論是無戶籍國民或外國人，只要是沒有戶籍的人，總是被當作例外處理，而無戶籍國民在例外規定中總是被遺忘，本頁面可以查詢對無戶籍國民不友善的法規。

「不友善」的定義​

所謂「不友善」者，分為以下幾類樣態：

  • 以戶籍作為享有權利的要件

    • 以「戶籍」作為享有權利的要件，導致無論是無戶籍國民或外國人，只要是無戶籍者，均無法享有該項權利。

  • 以持有國民身分證作為作為享有權利的要件

    • 以持有「國民身分證」作為作為享有權利的要件，導致無論是無戶籍國民或外國人，只要是無身分證者，均無法享有該項權利。

  • 本國人及外國人定義問題

    • 本國人定義為持有「國民身分證」或「在國內設有戶籍」者，外國人定義為持「居留證」者，致使持居留證的無戶籍國民，既無法適用本國人規定，亦無法適用外國人規定。

  • 居留證名稱問題

    • 針對沒有「國民身分證」者，要求提出「外僑居留證」作為身分證明文件，致使持「臺灣地區居留證」的無戶籍國民，無法享有該項權利。或者，由於永久居留證作為享有權利的要件，致使持「臺灣地區居留證」的無戶籍國民，其權利劣於持永久居留證之外國人。

對無戶籍國民產生的影響​

  • 無戶籍國民與有戶籍國民，不只憲法所定公民權，恐連基本生活權益都產生落差，無戶籍國民形同二等公民。
  • 連外國人民都可以享有的權利，無戶籍國民卻無從享有，導致本國國民的權益不如外國人民的不合理現象。
